# Автомонтаж Reels / Shorts нейросетью

Ты снимаешь говорящее видео — нейросеть режет паузы, «ээ» и дубли, ставит субтитры
(1–3 слова, главное слово цветом), прикрывает склейки приближением, делает плавные наезды,
крупные надписи на главных моментах, выравнивает звук до −14 LUFS и подмешивает музыку.
Всё по гайду «Как научить нейросеть монтировать видео».

## Что внутри

- `montage.py` — сам монтажёр (ffmpeg + faster-whisper)
- `setup/install.sh` — установка на macOS / Linux
- `setup/install.ps1` — установка на Windows
- `CLAUDE.md` — как Claude должен монтировать (порядок шагов)
- `prompts/montage.md` — готовый промт для монтажа + шпаргалка
- `prompts/carousel.md` — промт для каруселей Instagram

## Как пользоваться на своём компьютере

1. Поставь **Claude Code** (приложение Claude на компьютере → Claude Code) и открой в нём этот репозиторий.
2. Напиши: **«Установи всё для монтажа»** — Claude запустит `setup/install.ps1` (Windows)
   или `setup/install.sh` (Mac). Разреши установку. Ставятся ffmpeg, Python, faster-whisper, Node.js.
3. Создай папку без русских букв и пробелов, например `C:\reels\reel1`, положи туда видео
   (и музыку, если нужна).
4. Напиши: **«Смонтируй видео из C:\reels\reel1 по правилам video-editor»**.
5. Забери `C:\reels\reel1\out\final.mp4` и прочитай `out\report.md` — там что вырезано и что проверить.

Без нейросети тоже работает (но без вырезки дублей и умных акцентов):
```
python video-editor/montage.py auto C:\reels\reel1\video.mp4 --lang ru
```

## Как пользоваться в облаке (claude.ai/code)

Загрузи видео в чат и попроси смонтировать. Окружение ставится само при старте сессии
(`.claude/hooks/session-start.sh`). Для распознавания речи окружению нужен доступ к
`huggingface.co` (оттуда скачивается модель Whisper): настройки окружения → Network access →
добавить `huggingface.co` в Allowed domains.

## Графика как у автора гайда (Remotion)

Анимированная графика (цифры, списки, схемы) делается плагином Remotion:
Claude → Customize → Connectors → поиск «remotion» (в Codex: «Плагины» → Remotion → «Установить»).
Это включается в приложении, не из репозитория. Базовый монтаж выше работает и без него.
