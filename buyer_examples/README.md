# Образцы фото для покупателя

Проще всего — загрузить образцы прямо в @OtzyvSK_bot: администратор пишет
/examples, выбирает документ и присылает фото (до 10 на документ). Бот хранит
их у себя в базе — в репозиторий ничего класть не нужно. Замажьте имена,
номера, серии и подписи: образцы видит любой покупатель.

Запасной вариант — файл здесь, по одному на документ, с именами:
land_status.jpg, gz_agz.jpg, itu.jpg, egrpni.jpg, expertise.jpg,
license.jpg, registry.jpg (договор — по желанию: contract.jpg,
тогда укажите example="contract" в osk_bot/buyer.py). Загруженные через
/examples образцы важнее файла.

Если образца нет — бот просто покажет текстовую инструкцию без картинки.
