# Автопереключатель раскладки RU ⇄ EN

Работает как Punto Switcher: набрали слово не в той раскладке, нажали **пробел** —
слово тут же перепечатывается правильно, а раскладка переключается.

```
ghbdtn␣  →  привет␣     (и раскладка становится русской)
руддщ␣   →  hello␣      (и раскладка становится английской)
z ljvf␣  →  я дома␣     (однобуквенное слово перед ошибкой тоже исправляется)
Ghbdtn,␣ →  Привет,␣    (регистр и знаки препинания сохраняются)
```

Работает в любой программе: Telegram, браузер, Word и т.д.

## Запуск на Mac

1. Проверьте, что включены обе раскладки: **Системные настройки → Клавиатура → Источники ввода**
   (нужны «Русская» или «Русская – ПК» и «ABC» или «U.S.»).
2. Дважды щёлкните `start_switcher.command`. Если Mac пишет, что файл от неизвестного разработчика, —
   щёлкните по нему правой кнопкой → **Открыть**. При первом запуске он сам установит зависимости.
3. **Дайте права Терминалу** — без этого macOS просто не показывает программе нажатия, и ничего не
   происходит. Откройте **Системные настройки → Конфиденциальность и безопасность** и включите
   «Терминал» в двух списках: **Универсальный доступ** и **Мониторинг ввода**
   (если его там нет — «+» → Программы → Утилиты → Терминал).
4. **Полностью закройте Терминал (Cmd+Q)** и снова запустите `start_switcher.command`.
   Когда всё в порядке, после первого нажатия любой клавиши в окне появится
   «⌨️ Нажатия клавиш видны — переключатель работает».

Проверяйте в Заметках, Telegram или браузере. В полях для пароля и в самом Терминале
(если включён «Защищённый ввод с клавиатуры») macOS скрывает нажатия от всех программ.

Если что-то не так, запустите в Терминале из папки `layout_switcher` проверку
`.venv/bin/python mac_selftest.py` — она скажет, чего не хватает.

**Автозапуск:** Системные настройки → Основные → Объекты входа → «+» → `start_switcher.command`.

## Запуск на Windows

1. Установите Python 3 с [python.org](https://www.python.org/downloads/)
   (при установке отметьте галочку **Add Python to PATH**).
2. Убедитесь, что в Windows добавлены обе раскладки: русская и английская.
3. Дважды щёлкните `start_switcher.bat`. Окно с надписью «Переключатель раскладки запущен»
   должно оставаться открытым (его можно свернуть).

**Автозапуск вместе с Windows:** нажмите `Win+R`, введите `shell:startup`, нажмите Enter
и положите в открывшуюся папку ярлык на `start_switcher.bat`.

Чтобы переключатель работал и в программах, запущенных от имени администратора,
запускайте его тоже от имени администратора.

## Горячие клавиши

- **Pause** на Windows / **Shift два раза подряд** на Mac — отменить последнюю замену.
  Отменённое слово больше не будет исправляться до перезапуска. Если замены не было —
  перевести последнее слово вручную (или недописанное слово перед курсором).
- **Shift+Pause** на Windows / **Ctrl+Shift+X** на Mac — выключить / включить автопереключение
  (например, перед вводом пароля).

## Если какое-то слово исправляется зря

Добавьте его в `exceptions.txt` (по одному слову в строке) и перезапустите переключатель.

## Как он решает, что слово набрано не в той раскладке

1. **Словарь**: 40 000 самых частых русских и английских слов (`data/ru.txt`, `data/en.txt`).
   Если «ghbdtn» — не английское слово, а «привет» — русское, слово меняется.
   Если слово есть в обоих языках («рук» / «her»), оно меняется, только когда второй
   вариант встречается в десятки раз чаще.
2. **Буквосочетания**: для слов не из словаря (фамилии, редкие формы) сравнивается, насколько
   типичны сочетания букв для каждого языка: «ntktuhfv» → «телеграм».
3. Не трогаются слова с цифрами, смешанным алфавитом, «сЛОМАННЫМ» регистром и одиночные буквы
   (кроме случая «z ljvf» выше).

Проверка на 40 000 частых слов каждого языка: правильно набранное слово ошибочно
заменяется реже чем в 0,02 % случаев. Чаще всего ошибается на коротких аббревиатурах
вроде «vs» → «мы» — такие слова и стоит добавлять в исключения.

## Другие системы

- **Linux (X11)**: слова исправляются; чтобы переключалась и раскладка, установите `xkb-switch`.
  Wayland не поддерживается.
