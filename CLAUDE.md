# telegram-doc-bot

- `doc_bot.py` — Telegram-бот для сбора документов (деплой через nixpacks).
- `video-editor/` — автомонтаж Reels/Shorts и промты для каруселей.
  Когда просят смонтировать видео, установить всё для монтажа или сделать карусель —
  сначала прочитай `video-editor/CLAUDE.md` и действуй по нему.
