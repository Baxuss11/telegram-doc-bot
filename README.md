# @OSK_Tech_bot — технический рейтинг ОСК

Telegram-бот для выездной проверки документации на стройке. Он ведёт проверяющего
по всем пунктам по порядку: человек фотографирует документ, отмечает галочками
выполненные критерии, бот считает баллы. В конце бот:

- присылает PDF-отчёт с баллами и фото прямо в чат;
- сохраняет фото и отчёт на Google Диск в папку `Тех РЕЙТИНГ / Компания / ЖК / дата`;
- добавляет строку в Google Таблицу «ОСК — Технический рейтинг»: лист «Рейтинг»
  (одна проверка — одна строка) и лист «Детали» (по каждому критерию).

Пользоваться ботом могут только сотрудники, которым администратор открыл доступ.
Прерванная проверка не теряется: «/start → ▶️ Продолжить».

## Пункты и баллы

Максимум — 38 баллов. Все пункты, баллы и пороги оценки
(30+ «Хорошо», 20+ «Удовлетворительно») заданы в одном файле
[`osk_bot/checklist.py`](osk_bot/checklist.py). Юридическую часть позже можно
добавить туда же отдельной группой пунктов.

## Настройка

### 1. Токен бота

Старый токен был записан в коде, а репозиторий публичный, поэтому его нужно заменить:

1. В Telegram откройте @BotFather → `/mybots` → `@OSK_Tech_bot` → **API Token** → **Revoke current token**.
2. Скопируйте новый токен. Никуда его не вставляйте, кроме переменной `BOT_TOKEN` на хостинге (шаг 3).

### 2. Google Диск и Таблица (Apps Script)

Бот сохраняет файлы через небольшой скрипт Google, который работает от имени
владельца папки. Сервисный аккаунт для обычного Gmail не подходит: у него нет
своего места на Диске, и загрузка фото падает с ошибкой.

1. Откройте https://script.google.com под аккаунтом владельца папки «Тех РЕЙТИНГ» → **Новый проект**.
2. Вставьте содержимое файла [`apps_script/Code.gs`](apps_script/Code.gs) вместо кода по умолчанию.
3. В строке `const SECRET = '...'` впишите длинный случайный пароль (например, 30+ букв и цифр).
   Этот же пароль позже станет значением `APPS_SCRIPT_SECRET`.
4. Сохраните. Сверху выберите функцию `authorize` → **Выполнить** → разрешите доступ.
   Google предупредит, что приложение не проверено, — это ваш собственный скрипт:
   **Дополнительно → Перейти к проекту**.
5. **Начать развёртывание → Новое развёртывание** → тип **Веб-приложение**:
   - Запуск от имени: **Я**
   - Кто имеет доступ: **Все**
6. Скопируйте **URL веб-приложения** (заканчивается на `/exec`) — это `APPS_SCRIPT_URL`.

Если позже поменяете код скрипта: **Начать развёртывание → Управление развёртываниями →
✏️ → Версия: новая**. Тогда URL останется прежним.

### 3. Хостинг (Railway)

Бот должен где-то работать круглосуточно — это и есть хостинг. В репозитории
есть `nixpacks.toml` для Railway.

1. Railway → проект с ботом → сервис → **Variables**:

   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | новый токен из шага 1 |
   | `ADMIN_IDS` | ваш Telegram ID (узнать: команда `/myid` в боте или @userinfobot); можно несколько через запятую |
   | `APPS_SCRIPT_URL` | URL из шага 2 |
   | `APPS_SCRIPT_SECRET` | пароль из шага 2 |
   | `DATA_DIR` | `/data` |

2. Сервис → **Settings → Volumes → New Volume**, путь монтирования `/data`.
   Там хранится база: незавершённые проверки и список сотрудников. Без диска
   всё это стирается при каждом перезапуске.
3. Перезапустите сервис (Deploy). В логах должна появиться строка
   `Google Диск подключён, корневая папка: Тех РЕЙТИНГ`.

### 4. Доступ сотрудникам

Сотрудник пишет боту `/start` → «🔑 Запросить доступ». Администратору приходит
запрос с кнопками «✅ Разрешить / ❌ Отклонить». Список сотрудников и отключение
доступа — команда `/staff` (только для администратора).

## Запуск локально

```bash
pip install -r requirements.txt
export BOT_TOKEN=... ADMIN_IDS=... APPS_SCRIPT_URL=... APPS_SCRIPT_SECRET=...
python3 doc_bot.py
```

Без `APPS_SCRIPT_URL` бот тоже работает, но отчёт будет только в чате.

## Устройство

- `doc_bot.py` — точка входа.
- `osk_bot/checklist.py` — пункты, критерии, баллы, пороги оценки.
- `osk_bot/handlers.py` — диалог: доступ, карточки пунктов, завершение.
- `osk_bot/db.py` — SQLite: сотрудники, проверки, отметки, фото (Telegram `file_id`).
- `osk_bot/report.py` — PDF-отчёт (шрифт DejaVu в `fonts/`).
- `osk_bot/gdrive.py` + `apps_script/Code.gs` — Google Диск и Таблица.
