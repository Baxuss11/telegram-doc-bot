# ad_analytics — расход Meta vs заявки Bitrix24 по креативам

Модуль берёт расход по каждому объявлению из Meta (Facebook/Instagram) и заявки из
Bitrix24, связывает их по имени объявления и считает **цену заявки** и **цену
квалифицированного лида по каждому креативу**. Это и есть та часть ТЗ, что была
помечена «способ подключения к Claude уточнит отдельно».

## Принцип

- **Ключ связывания — имя объявления.** В Meta это `ad_name`, в Bitrix — `utm_content`
  (по ТЗ в объявлениях стоит `utm_content={{ad.name}}`). Имена нормализуются
  (регистр, пробелы), поэтому «Video_A v1» и «video_a  v1» сходятся.
- **Квалификация** читается из поля лида (по умолчанию стадия `STATUS_ID`,
  значение `CONVERTED`). Можно указать своё поле-список.
- **Секреты — только в окружении.** Токен и вебхук не попадают ни в код, ни в
  логи, ни в чат. Это закрывает замечание из раздела безопасности ТЗ: бессрочный
  ключ не нужно вставлять в переписку — он живёт в секретах сервиса.

## Настройка

1. Скопируйте `.env.example` в `.env` и заполните (см. комментарии в файле):
   `META_ACCESS_TOKEN`, `META_AD_ACCOUNT_IDS`, `BITRIX_WEBHOOK_URL`.
2. Экспортируйте переменные в окружение (локально: `set -a && . ./.env && set +a`,
   на сервере — через секреты платформы).

## Запуск

```bash
python -m ad_analytics --days 30                 # последние 30 дней, таблица
python -m ad_analytics --since 2026-10-01 --until 2026-10-27
python -m ad_analytics --days 30 --format json   # машинный вывод (для Claude/бота)
```

`--format json` отдаёт структуру с полями `rows`, `totals`, `wasted`
(креативы, которые тратят деньги без заявок) и `unmatched_leads` (заявки без
ключа связывания). Именно JSON удобно передавать Claude как данные инструмента.

## Коды возврата

`0` — ок · `2` — не заданы переменные окружения · `3` — ошибка Meta
(токен/доступ к кабинету) · `4` — ошибка Bitrix24 (вебхук/права/поле).

## Требуемые права

- Meta: достаточно **`ads_read`** (чтение статистики). Запись в кабинет модуль не
  делает — `ads_management` не нужен.
- Bitrix24: вебхук с правом **`crm`** (чтение лидов).

## Тесты

```bash
python -m unittest tests.test_report -v
```
